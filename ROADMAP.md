Exit gate passed on real ticks 2026-10-25: SPY 2026-10-23 whole session (3.8M ticks) identical across all three paths, re-checked on the final code; 25-day run on final settings: ~21 sweeps and ~9–14 large prints a day after warm-up, VPIN on 24/25 days (docs/demo/phase-3.md). Phase 4 progress (2026-10-26, ADR-0013): RiskGuard, persisted loss halts, kill switch (CLI + file; dashboard button in Phase 6), GuardedStrategy (IOC entry, stop for the shares actually bought, target watched in code, cancel-confirm-sell flatten), watchdog process, backtest latency/fill models. Native brackets dropped: Nautilus releases bracket stops at full size on partial fills (docs/research/13). Chaos tests pass on the Nautilus simulated venue: feed drop, stale quotes, clock skew, halts, rejects, partials, duplicates, kill switch, daily loss, end of day, frozen node, account mismatch (docs/demo/phase-4.md). IBKR paper drills for IOC, stops and the watchdog are Phase 7 items.

Phase 5 progress (2026-10-26, ADR-0014): five setups pre-registered before any real-data run (docs/research/14, commit b11f264): stacked-imbalance, large-print and multiple-node pullbacks, support zone + confirmation, buy-side sweep. Pure `SignalEngine` + `plan`, fast NBBO simulator, walk-forward (20 train / 10 test days, 4 folds, 20 trials), day-block bootstrap + Holm + deflated Sharpe + random control, $10,000 account check with every risk limit, Nautilus cross-check, OrderFlowStrategy on GuardedStrategy, Jev gate (pinned, 750 ms, NO TRADE on failure, off by default, offline evaluation with calibration). Tested on made-up data only; the 60-day real-data run (2026-07-31 … 2026-10-23) runs on the operator's PC (docs/runbooks/walkforward.md).

Phase 6 progress (2026-10-26, ADR-0015): read-only FastAPI over the journals, heartbeat, risk state, tape snapshot and reports; no-build dashboard (Taste Skill "data-terminal" style) with all eight screens and an engage-only kill switch button; ntfy/Telegram alert relay; 09:00 pre-market check and post-close end-of-day report; demo mode for a walkthrough before paper; runbooks dashboard.md, alerts.md, daily-ops.md (docs/demo/phase-6.md). Redis Streams / TimescaleDB journal deferred to the Phase 7 review; files remain the record.

Phase 7 progress (2026-10-26, ADR-0016): paper node (`flowforge.ops.paper_node`: Alpaca data, features, OrderFlowStrategy, RiskGuard, IB execution; refuses non-paper; only walk-forward-passing setups trade, otherwise shadow), IBKR paper drills (instruments, round-trip, stop, watchdog takeover, restart with unknown shares), restart soak, and the exit-gate scorecard refreshed after each close and shown on the dashboard (docs/demo/phase-7.md). Tested offline only. Day-trade rule settled 2026-10-26: the operator's IBKR account is a Cash account, so `pdt_regime: cash` (no day-trade count; buys limited to settled cash). Open operator decision: live feed (IEX vs SIP). The 4-week clock starts when a setup passes the real-data walk-forward and the drills pass.

Interim (2026-10-25, ADR-0009): practice backtest on 1-minute bars (opening range breakout, long only, risk limits applied). Tests the backtest machinery only; it is not a gate and doesn't replace Phases 2–5.

Automatic demotion one stage on drawdown, slippage, calibration drift or error-rate breach. Research Scout re-runs monthly.
